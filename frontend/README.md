# Frontend

Next.js app (screens only). See the project root `CLAUDE.md` and `PLAN.md`.

```bash
npm install
cp .env.local.example .env.local   # optional, defaults to http://127.0.0.1:8000
npm run dev                         # open http://localhost:3000, not 127.0.0.1:3000 (CORS allows only localhost)
npm test
npm run lint
```
